# M2-2 精度实测记录

> 本文件用于现场填数。三组实验对应题目要求：距离线性度、姿态响应、畸变开/关。
> 每格至少 5 帧，原始值写进表里，均值和误差按下面公式算。
> 开发时的自检数据单独放在最后一节，**不要把它当正式实测**。

## 0. 测试条件（每次测前填）

| 项 | 值 |
| :-- | :-- |
| 日期 / 测试人 |  |
| 相机型号 / 镜头 |  |
| 分辨率 / 帧率 | 1920 × 1080 / 15 FPS（MJPG） |
| 标定文件 | `../M2-1/camera_calibration.yaml` |
| 方格实测边长 | 17.0 mm（如重打，填新值并加 `--square-mm`） |
| 光照 |  |
| 靶标固定方式 |  |
| 距离测量工具 | 卷尺 / 激光测距仪，精度 ______ mm |
| 角度测量工具 | 量角器 / 手机水平仪，精度 ______ ° |

统一约定：

- 距离用 `distance_m`（到靶标中心的欧氏距离）；靶标居中、正对时与 `z_m` 几乎相同。
- 角度用 `roll_deg / pitch_deg / yaw_deg`，单位度，正负按右手定则。
- 只统计 `detected=1` 的帧；检出率 = `detected=1` 的行数 ÷ 总行数，也记下来。
- 每一档先看 `reproj_px`：正常应 < 1–2 px；若明显偏大，先查光照、倾斜、对焦，
  不要直接把这帧算进精度。

## 1. 距离线性度

### 1.1 做法

1. 靶标贴平、固定，标题朝上；相机固定在支架上，光轴尽量对准靶标中心。
2. 用卷尺量**相机镜头前端到靶标中心**的距离，记为实际距离。
3. 在 0.30 / 0.50 / 0.80 / 1.20 m 四档，每档录 5 秒或拍 5 帧；取中间稳定帧。
4. 记录每帧 `distance_m`，算均值、标准差、绝对误差、相对误差。

### 1.2 原始数据（单位：m）

| 实际距离 | 第 1 帧 | 第 2 帧 | 第 3 帧 | 第 4 帧 | 第 5 帧 | 均值 | 标准差 | 绝对误差 | 相对误差 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| 0.300 |  |  |  |  |  |  |  |  |  |
| 0.500 |  |  |  |  |  |  |  |  |  |
| 0.800 |  |  |  |  |  |  |  |  |  |
| 1.200 |  |  |  |  |  |  |  |  |  |

计算公式：

```text
均值     mean = (z1 + ... + z5) / 5
标准差   std  = sqrt( Σ(zi - mean)² / (5 - 1) )      # 样本标准差
绝对误差 err  = mean - 实际距离                       # 带符号；表里也可写 |err|
相对误差      = |err| / 实际距离 × 100%
```

### 1.3 命令

```bash
# 一档一个目录，每档 5 张（distance_030/、distance_050/、distance_080/、distance_120/）
python3 pose_estimate.py --image distance_030/ \
    --calib ../M2-1/camera_calibration.yaml --headless --csv results/dist_030.csv

# 或者用视频，一次录 5 秒，再离线处理
python3 pose_estimate.py --video distance_030.mp4 \
    --calib ../M2-1/camera_calibration.yaml --headless --csv results/dist_030.csv
```

CSV 每帧一行，`detected=1` 时 `distance_m` 有效。快速统计（可直接改路径）：

```bash
python3 - <<'PY'
import csv, statistics
path = 'results/dist_030.csv'
z = [float(r['distance_m']) for r in csv.DictReader(open(path, encoding='utf-8'))
     if r['detected'] == '1']
print(f'n={len(z)}  mean={statistics.mean(z):.4f} m  '
      f'std={statistics.stdev(z)*1000:.2f} mm  '
      f'err={(statistics.mean(z)-0.300)*1000:+.2f} mm')
PY
```

### 1.4 结论（填）

- 0.30–1.20 m 内最大绝对误差：______ mm
- 最大相对误差：______ %
- 误差随距离是否单调增大：______
- 是否满足现场要求（例如 ±10 mm / ±2%）：______

## 2. 姿态响应

### 2.1 做法

1. 靶标中心到相机距离固定在约 0.5 m，先确认正对时三个角接近 0。
2. 分别绕三个轴转动：
   - **yaw**：绕竖直轴左右转（靶标法线在水平面内偏）；
   - **pitch**：绕水平轴上下俯仰；
   - **roll**：绕光轴在自身平面内转。
3. 每个轴测 30° / 60° / 90° 三档；用量角器或手机水平仪记录实际角。
4. 每档取 5 帧，记录对应角的输出值、均值、误差。

> 90° 时棋盘格接近侧视，可能检不到或 RMSE 变大，这是正常边界；如果 90° 无法稳定
> 检出，如实记录“检出率”，不要为了凑数硬填。

### 2.2 原始数据（单位：°）

| 轴 | 实际角 | 第 1 帧 | 第 2 帧 | 第 3 帧 | 第 4 帧 | 第 5 帧 | 均值 | 误差 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| yaw | 30 |  |  |  |  |  |  |  |
| yaw | 60 |  |  |  |  |  |  |  |
| yaw | 90 |  |  |  |  |  |  |  |
| pitch | 30 |  |  |  |  |  |  |  |
| pitch | 60 |  |  |  |  |  |  |  |
| pitch | 90 |  |  |  |  |  |  |  |
| roll | 30 |  |  |  |  |  |  |  |
| roll | 60 |  |  |  |  |  |  |  |
| roll | 90 |  |  |  |  |  |  |  |

误差 = 输出均值 − 实际角（带符号）。如果实际角是反向转的，先确认符号约定：
右手定则，拇指指向该轴正方向，四指弯曲方向为正转。

### 2.3 命令

```bash
# 每个姿态录一段视频或拍 5 张
python3 pose_estimate.py --video yaw_30.mp4 \
    --calib ../M2-1/camera_calibration.yaml --headless --csv results/yaw_030.csv
```

```bash
python3 - <<'PY'
import csv, statistics
path = 'results/yaw_030.csv'
rows = [r for r in csv.DictReader(open(path, encoding='utf-8')) if r['detected'] == '1']
for key in ('roll_deg', 'pitch_deg', 'yaw_deg'):
    v = [float(r[key]) for r in rows]
    print(f'{key}: mean={statistics.mean(v):+.2f}  std={statistics.stdev(v):.2f}')
PY
```

### 2.4 结论（填）

- 三个轴是否都能单调响应：______
- 30°/60° 最大误差：______°
- 90° 是否可稳定检出：______（检出率 ______）
- 正对时零位偏差（roll/pitch/yaw）：______ / ______ / ______ °

## 3. 畸变开 / 关对比

### 3.1 做法

1. 同一帧图像，分别用带畸变（默认）和不带畸变（`--no-distort`）解 PnP。
2. 也可以直接用 `--compare-distort`：程序内部用同一组角点分别解两次，打印
   `|Δt|`、`Δroll`、`Δpitch`、`Δyaw`。
3. 在 0.30 / 0.80 / 1.20 m 各测一次；每次测**画面中心**和**画面边缘**两个位置。
   边缘位置更能体现畸变影响（M2-1 的 k1=+0.0799、k3=+0.3504，边缘径向位移更大）。
4. 记录两种结果的绝对值和差值。

### 3.2 原始数据

| 距离 (m) | 画面位置 | 带畸变 t (x,y,z) | 不带畸变 t (x,y,z) | \|Δt\| (mm) | 带畸变 (r,p,y) | 不带畸变 (r,p,y) | Δroll | Δpitch | Δyaw |
| :--: | :--: | :-- | :-- | :--: | :-- | :-- | :--: | :--: | :--: |
| 0.30 | 中心 |  |  |  |  |  |  |  |  |
| 0.30 | 边缘 |  |  |  |  |  |  |  |  |
| 0.80 | 边缘 |  |  |  |  |  |  |  |  |
| 1.20 | 边缘 |  |  |  |  |  |  |  |  |

> 表中 t 单位 m，角度单位 °；`|Δt|` 转成 mm 便于看。Δ = 带畸变 − 不带畸变。

### 3.3 命令

```bash
# 直接打印同一帧的差值
python3 pose_estimate.py --image edge_030.png \
    --calib ../M2-1/camera_calibration.yaml --compare-distort --headless

# 或者分两次跑，保存两份 CSV，再自己作差
python3 pose_estimate.py --image edge_030.png \
    --calib ../M2-1/camera_calibration.yaml --headless --csv results/edge_030_dist.csv
python3 pose_estimate.py --image edge_030.png --no-distort \
    --calib ../M2-1/camera_calibration.yaml --headless --csv results/edge_030_nodist.csv
```

- 中心区域 |Δt| 最大：______ mm，角度最大差：______°
- 边缘区域 |Δt| 最大：______ mm，角度最大差：______°
- 边缘是否明显大于中心：______
