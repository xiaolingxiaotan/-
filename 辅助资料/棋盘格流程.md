findChessboardCorners
├─ 参数/类型检查，BGR→GRAY
├─ [flag] NORMALIZE_IMAGE → equalizeHist
├─ [flag] FAST_CHECK（可选快速否决）
│   ├─ 直方图阈值二值化 → checkChessboardBinary
│   ├─ 失败 → 旧版 checkChessboard
│   └─ 仍失败 → 直接 return false（不再做完整检测）
└─ 主检测：方法 A → 失败则方法 B
   │
   ├─ 方法 A：直方图自适应阈值（默认走这条）
   │   ├─ icvBinarizationHistogramBased() 二值化
   │   ├─ 图像四周补一圈白线（防止贴边的格子被 findContours 漏掉）
   │   └─ for dilations = 0..max_dilations
   │       └─ processQuads()
   │           ├─ generateQuads()
   │           │   ├─ findContours(RETR_CCOMP)
   │           │   ├─ 只保留“洞”轮廓（即黑格）
   │           │   ├─ 面积过滤
   │           │   ├─ approxPolyDP 逼近 → 必须 4 边、凸
   │           │   └─ [flag] FILTER_QUADS：边长比/面积比过滤
   │           ├─ findQuadNeighbors() 建立格间邻接关系
   │           └─ 对每个连通组循环
   │               ├─ findConnectedQuads() 连通分组
   │               ├─ orderFoundConnectedQuads() 排成行列
   │               ├─ cleanFoundConnectedQuads() 去掉冲突/多余格
   │               └─ checkQuadGroup() 检查角点共享一致性
   │
   └─ 方法 B：A 失败时回退的旧路径
       ├─ [flag] NORMALIZE_IMAGE → equalizeHist
       ├─ 非 adaptive：固定阈值，循环不同 k
       ├─ adaptive：adaptiveThreshold，blockSize 递增
       └─ dilations 循环 → processQuads()（同上）
└─ 后处理
    ├─ 角点离图像边界太近 → 判失败
    ├─ 宽高都为偶数时的顺序修正
    ├─ cornerSubPix() 亚像素细化
    └─ checkBoardMonotony() 行列单调性校验
└─ 输出：行优先、有序的角点
