# 问题一：遍历value列时把键值写成“Value”
- 定位与现象：读取完csv表后对得到的迭代器进行遍历时，v = float(row["Value"])显示键值错误KeyError: 'Value'
- 原因：在csv文件中第二列的表头为小写的“value”，而不是“Value”
- 修改：将“Value”改为“value”

# 问题二：没有自动创建输出文件
- 定位与现象：在输出清洗的数据时，在f = open(output_path, "w")行显示文件未找到错误FileNotFoundError: [Errno 2] No such file or directory: '/out/cleaned_data.csv'
- 原因：在打开这个路径之前，只是将文件路径拼接，没有创建这个输出文件夹，而open函数的write模式只能创建文件不能创建文件夹
- 修改：将输出文件创建出来————用os.makedirs()函数（使用绝对路径）

# 问题三：标准差的计算结果为0
- 定位与现象：结果输出的标准差为0，不符合表中数据的实际，定位到标准差的代码：acc += (v - mean)
- 原因：根据标准差的计算公式，这里加的应该是(v - mean)的平方，且就算加上了平法，得到的std也是方差，还要取根号
- 修改：将(v - mean)带上平方，且std加上取根号操作（为了更好的维护代码，将标准差和均值的计算封装为函数）

# 问题四：离群值的剔除只有上限没有下限
- 定位与现象：在剔除离群值的代码判断条件v > mean + 2 * std中，只有取值上限
- 原因：剔除离群值应该是大于或者小于范围的视为离群而剔除，而不是只有上限
- 修改：加上或者小于下限（同样将离群值剔除封装为函数）

# 问题五：没有用函数封装,没有***if __name__ == "__main__"***保护
- 定位与现象：所有逻辑都平铺在全局作用域，没有封装进函数，而且没有代码保护
- 原因：代码复用、调试和定位问题不方便
- 修改：接着问题三四将其他函数功能封装进函数，并写一个主函数调用，加上*if __name__ == "__main__"*保护

# 问题六：没有将清洗完的数据加入cleaned列表
- 定位与现象：跑一遍代码显示清洗后剩余0条
- 原因：发现--- 输出清洗后的数据 ---之前没有将清洗完的数据加入cleaned列表的相关代码，因此输出的cleaned列表是空列表
- 修改：添加将清洗完的数据加入cleaned列表的代码进入remove_outliers函数

# 问题七：硬编码了路径，无法自定义文件路径
- 定位与现象：如果不在工作目录下运行代码就会找不到文件
- 原因：文件硬编码了路径，没有读取命令行参数的能力
- 修改：添加`argparse` 解析命令行参数，然后添加一个路径读取函数

# 问题八：没有异常处理
- 定位与现象：如果输入异常值或者出现找不到文件，没有对应的处理
- 原因：没有try-except块的相关代码
- 修改：添加异常处理
