# linux环境搭建与选择
## 选择物理机（双系统），虚拟机还是wsl
-首先通过B站视频了解三种方式各自的优缺点：
虚拟机的优点是方便且功能完善，而且绝对安全与物理隔离；但是缺点是系统太重了，需要较大的内存空间。
物理机的优点是能够最大限度的使用硬件，从性能上效果是最好的，缺点是需要重启电脑来回切换Windows和Linux系统，不方便。
wsl则是既能够再Windows和Linux系统切换方便，而且可以很便捷的使用Windows上的软件进行工作，占用内存也不多，缺点是硬件直通很差，调硬件很麻烦。

-由于我自己的意向是视觉模型训练与部署，所以不需要去调电机等硬件，无需考虑硬件直通问题，并且电脑内存不是很够，所以综合考虑使用wsl作为开发环境。

## **遇到问题**：下载wsl和Ubuntu
-最开始我是直接通过Windows Power Shell用命令行install，但是由于校园网的拦截，下了三个小时才86%，并且在这时断了链接，分析原因应该是校园网拦截了本次链接。于是，通过询问AI了解了镜像源等概念，最后在中科大的镜像源网站中下载到Ubuntu22.04，并且通过流量下载避免了校园网的拦截。

-总结：之后下载国外网站的相关资料或软件包尽量不要使用校园网，可以找找镜像源。

# python c/c++与ROS2环境的安装
-python有conda和uv两种环境要选，其中conda可以同时管理python包和非python底层库，但是解析安装速度慢；uv则是由RUST语言编写的，安装编译速度快，但是由于conda在激活后会修改系统路径，所以可能会与ROS2编译时的python解释器冲突，所以不采用。

-c/c++与ROS2按照题目要求的版本安装。

-由于我本身用的是wsl，所以vscode只在windows系统里安装，然后安装插件远程连接到wsl2。
